IEEE-754 Floating-Point Processor

Technologies: Basys 3, Verilog, UART, I2C, AMD Vivado

Project Overview

Developed an IEEE-754 single-precision floating-point processor across two Basys 3 FPGA development boards.

System Architecture

The design incorporated custom arithmetic datapaths, FIFO buffers, and communication interfaces between FPGA modules.

My Contributions

Implemented carry-lookahead adders, a Wallace tree multiplier, FIFO buffering, and OLED output integration.
